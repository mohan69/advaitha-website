# Advaitha website

Static enterprise website for Advaitha, the governed Agentic AI architecture and advisory initiative of RightSense Technologies Private Limited.

## Positioning

Advaitha helps engineering-intensive manufacturers move from fragmented AI pilots to governed Agentic AI integrated with ERP, PLM, engineering and operational workflows.

## Local preview

```bash
python -m http.server 8080
```

Open `http://localhost:8080`.

## Deployment

The site is Netlify-compatible and includes clean-path redirects, security headers, `robots.txt` and `sitemap.xml`.

The canonical public domain is configured as `https://advaitha.tech/`. Update canonical URLs if a different production domain is chosen.
